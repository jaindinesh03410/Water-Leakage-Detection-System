🔑 FIREBASE SETUP (Required First Time Only)

  1. Go to: https://console.firebase.google.com/
  2. Open your project
  3. Settings → Service Accounts
  4. Click "Generate new private key"
  5. Save as: firebase-key.json (in this folder)
  6. Copy .env.example to .env
  7. Add your database URL to .env
