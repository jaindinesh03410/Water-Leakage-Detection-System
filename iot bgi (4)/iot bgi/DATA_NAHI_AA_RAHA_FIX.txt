  SOLUTION:

    taskkill /PID <PID_NUMBER> /F

  SOLUTION:
    - Backend restart करो
    - Browser cache clear करो (Ctrl+Shift+Delete)
    - Page reload करो (Ctrl+F5)

PROBLEM 6: Data दिख रहा but 0 या null
  SOLUTION:
    python fresh_test_data.py
    (3 seconds wait करो)
    Dashboard reload करो
